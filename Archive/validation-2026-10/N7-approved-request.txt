## 1부 — 방향 공격과 포고 (체인)

### ATK-1 위 공격
- 수정 허용: `PlayerAttack.cs`, `AttackFeedback.cs`, `CombatTuning.cs`(새 필드 추가만), CombatTuning.asset(새 필드 값만).
- 입력: 위 방향(Move.y > 0.5)을 누른 채 X → 위 공격. 지상·공중 모두 가능. 판정 시작·활성·쿨다운은 기존 공격과 공유한다.
- 판정: 플레이어 충돌체 윗면 위쪽, 폭 `upAttackWidth` 1.2u × 높이 `upAttackHeight` 1.3u.
- 표시: AttackSlash를 같은 박스 크기·위치로 표시(기존 표시 재사용).
- 합격(`Validation/N7-ATK1.txt`): 30/60/120fps에서 위 판정 박스 위치·크기 0.01u 이내, 위쪽 더미에 1타, 같은 높이 옆 더미에는 0타, 위 입력 없을 때 좌우 공격 결과가 기존과 동일, T3 기존 항목 전부 PASS, 회귀 묶음 PASS.

### ATK-2 공중 아래 공격 + 포고
- 수정 허용: ATK-1 파일 + `PlayerMotor.cs`·`PlayerDash.cs`에 **새 public 메서드만** 추가(`Bounce(float vy)`, `RefreshAirActions()` 등). 기존 메서드 변경 금지.
- 입력: **공중에서만** 아래 방향(Move.y < -0.5) + X → 아래 공격. 지상에서 아래+X는 기존 좌우 공격.
- 판정: 충돌체 아랫면 아래쪽, 폭 `downAttackWidth` 1.2u × 높이 `downAttackHeight` 1.3u.
- 포고: 아래 공격이 **적·보스·`PogoTarget`** 에 처음 명중한 순간, 플레이어 수직 속도를 `pogoVelocity`(초기 11u/s, 범위 9~13)로 설정한다. 공격 한 번당 포고는 1회. `pogoRefreshesAir`(초기 true)이면 더블 점프와 대시 사용 가능 상태를 회복한다(획득한 능력만).
- `PogoTarget` 새 컴포넌트: 피해를 받지 않고 포고만 일으킨다. 3부 테스트 방 가시에만 붙인다.
- 포고 직후 위험물 접촉 처리 순서: 같은 프레임에 아래 판정이 PogoTarget에 닿고 플레이어 몸이 KillZone에 닿으면 **포고를 먼저 적용**한다. 이것이 불가능하면 BUG로 기록하고, 판정 높이를 키우는 우회는 하지 않는다.
- 합격(`Validation/N7-ATK2.txt`): 30/60/120fps에서 공중 아래 공격 판정 박스 정확도, 지상 아래+X는 좌우 공격, 적 명중 시 vy=pogoVelocity, 공격당 포고 1회, 획득한 능력만 회복, 미획득 능력은 회복되지 않음, 빗나가면 포고 없음, 포고 높이 MEASURE(fps 간 차이 ±0.05u), 회귀 묶음 PASS.

### ATK-3 적·보스와 연결
- 수정 허용: ATK-2 파일 + 각 적/보스의 `ReceiveHit` 호출부는 **변경 금지**(이미 IDamageable로 공통 처리됨). 필요하면 PlayerAttack 쪽에서 처리한다.

## 2부 — 난이도 상향 (DEC-DIFF-001)
- 먼저 현재 모든 Tuning Asset을 `Assets/ScriptableObjects/Profiles/v1-normal/`에 복사해 백업한다(원본 GUID는 그대로, 복사본은 참조되지 않는 보관용).
- 그다음 원본 Asset 값을 아래 Hard 후보로 바꾼다. 모두 Prototype Value이고 사용자가 플레이해서 판단한다.

| 대상 | 현재 → Hard 후보 |
| --- | --- |
| Player HP / 무적 시간 | 5 → 4 / 1.0s → 0.8s |
| E1 | HP 2 → 3, 이동 1.8 → 2.5u/s |
| E2 | HP 3 → 4, 돌진 6 → 7u/s, 예고 -20% |
| E3 | 발사 주기 -20%, 탄속 +20% |
| 보스 | HP 20 → 28, 피해 1 → 2, 근접 예고 0.8 → 0.6s, 파형 예고 1.0 → 0.75s, 회복 1.2 → 0.8s, 파형 속도 5 → 6.5u/s |

- 보스 HP는 포고 연속 타격을 고려한 값이다. ATK-3에서 포고 최대 타수가 회복 구간당 4타 이상이면 HP를 32로, 1타 이하이면 24로 조정하고 그 이유를 기록한다.
- 확인(`Validation/N7-DIFF.txt`): 변경 전후 값 표, 회귀 묶음 PASS(값 의존 검사는 Asset 값을 읽도록 수정), 보스 처치 가능성(BossRetryVerifier를 새 값으로 실행. 사람의 회피 반응 시간을 0.25s로 두고 회피 가능 여부를 계산·기록), fps 행렬(N5 T-D) 재실행 결과가 기존과 같은지.
- 빌드 `Builds/S5-hard/Afterglow-S5-hard.exe`(1부 + 2부). 비교용 이전 빌드는 S4-pre3다.
- TASKS Before–After에 DIFF-001로 기록한다(Before: PT-001 관찰, After: 사용자 플레이 대기).
