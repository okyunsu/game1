# S3T-01 사용자 QA 요약 1쪽

## 바뀐 것
본편 선택 경로5곳에 포고 도전과 빛나는 사각형 표시를 추가했다. 접촉하면 사라지고 HUD에 발견 n/6이 누적된다. 방 이동·사망에는 세션 발견을 유지하며 타이틀 복귀 시 초기화한다. 저장·진행 보상은 없다. A-1/A04는 지정 입력 조정 후에도 실패해 추가 배치를 제외했다. 따라서 이번 최대 발견은 **5/6**이다.

H1 기본값 유지, H2/H3는 기존 빌드 보존만 했다. 적·보스 행동 패턴 작업은 BOSS-2 TODO이며 이번에는 구현하지 않았다. 보존 목록 밖 기존 빌드69개를 삭제했다.

## 어디서 해 보나
산출물: `Builds/S5-levels/Afterglow-S5-levels.exe`, 같은 폴더 `PogoTest 실행.bat`. **플레이 전 확인 필요**: 선택 경로 지정 입력은5/5 통과했지만 전체 자동 경로는 R06에서 차단되어 전체 완주 검증 빌드로 안내하지 않는다. R05 사망 없는 A05→A04→A03 귀환은 확인했다. G-D 연속 통과는 다음 R06에 해당하며 미확인이다. 게임의 필수 출구나 게이트를 자동 검사 통과를 위해 바꾸지 않았다.

- **A-2 / A05:** 대시 연습의 마지막 높은 블록 오른쪽. 가시 표적2개를 타고 오른쪽 끝 x34의 표시로 이동한다.
- **B-1 / B02:** 돌진 적 오른쪽 위 x20의 낮은 선택 선반. 아래 공격으로 튕긴 뒤 획득 대시로 접근한다.
- **B-2 / B04:** 더블 점프 연습 높은 블록의 오른쪽. 표적→추가 점프→대시로 x32.5의 높은 선반에 착지한다.
- **C-1 / C02:** 두 높은 블록 사이 아래의 표적 x18.5. 포고→추가 점프→대시로 위쪽 오른편 x22의 선반에 착지한다.
- **C-2 / C03:** E1 오른쪽 위 선택 선반과 E3 왼쪽 위 x27 선반. 최종 표시는 E3 쪽에1개다. 아래에서 위 공격하거나 적 위에서 아래 공격해 접근 동선을 비교한다. 지정 입력은 E3 포고→최종 선반만 확인했다.

## 의심 지점 3개
1. 포고·위 공격을 쓰는 선택이 재미있는지, 기존 길보다 단지 번거로운지. C-1 가시가 필수 길 점프 실패를 지나치게 벌하는지도 본다.
2. 몸이 가시에 먼저 닿을 때의 사망과 포고 타이밍이 읽히는지. 적을 먼저 처치하면 선택 경로 접근이 어려워져도 필수 진행이 막히지 않는지 확인한다.
3. 발견 표시의 밝기·HUD 가독성, 사망/방 재방문 유지와 타이틀 초기화, **5/6이 미완성으로 혼동되는지** 확인한다. 이 감각·화면 판단은 자동 PASS로 수락하지 않았다.

수정 위치: 각 방 Scene의 Optional/Discovery 오브젝트, 반복 표시는 `Assets/Prefabs/DiscoveryReward.prefab`의 ID·glowPeriod(초)·minimumOpacity. 배치 변경은 Play 종료 후 다시 입력하고 Scene을 저장한다. 공통 포고 값·공격 값·기존 적 수·난이도 기본값은 이번에 변경하지 않았다.
