# V2 직접 플레이 안내 — Batch 05

**실행:** [Play-V2.cmd](Builds/V2-delivery/Play-V2.cmd)를 더블클릭한다. 같은 폴더 Data/DLL을 유지한다. 별도 `progress-v2-qa.json` 슬롯을 쓰며 첫 실행은 새 게임, 이후에는 이어하기를 선택한다. exe 직접 실행은 기존 기본 저장 슬롯을 공유하므로 이 실행기를 사용한다.

←/→ 이동, Z 점프·추가 점프, C Dash, X 공격, 공중 ↓+X 포고, Esc Pause. B03의 ↑ 선택 입구는 의도적으로 위를 눌러 들어간다. 발견은 세션 한정 **18개**, 저장·성장 보상은 없다.

| 확인 순서 | 볼 항목 | 계획 시간 |
|---|---|---|
| A01~A06 | 넓어진 방의 3~5구간, 쉬운 필수 이동, 보이는 높은 선택 입구, A05 Dash→A03 G-D, A04 E1 회피 | **15~20분** |
| B01~B06 | B04 추가 점프→B01 높은 문, B05 넓은 상승, B03 ↑ 분기, B06 Dash·포고(추가 점프 없이) | 15~20분 |
| C01~C06 | 밝은 관측탑, C03 엄폐·선택 분기, C04 CP→보스, C06 기존 전투와 높은 선택 전망 | 15~20분 |

시간은 사람 플레이 계획치이며 실측하지 않았다. 먼저 A지역만 보고 중단해도 된다. 비교할 것은 **방의 밀도·기억할 단서·필수/선택 난이도 차이·픽셀 스타일**이다. 기존 기본/AV1/B2 빌드는 그대로 남아 있다.

수정 위치: [LEVEL_V2.md](../../LEVEL_V2.md)의 설계표, `Assets/Scenes/V2/`의 지형 Transform·카메라 Boundary·문·CP·적 Reset 위치. 반복 시각은 `Assets/Prefabs/V2/`, 이동·전투 수치는 기존 Tuning Asset 한 곳 그대로다. Play 중 바꾼 Scene 값을 메모한 뒤 **Stop 후 Scene에 다시 반영·저장하고 V2 재빌드**한다.

[전체 검증·인계](../../TASKS.md#latest-handoff). 기술 PASS는 사람 난이도·스타일 수락을 대신하지 않으며, 기본 교체·Sprint Gate는 아직 대기한다.
