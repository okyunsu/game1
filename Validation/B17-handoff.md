# B17 T6 — 피드백 원인과 인계

TASKS에 Batch17 현재 상태·Task 표·Latest Handoff, README에 draft2 실행 안내를 갱신했다. 피드백3건은 지형/경계 데이터로 분류했고 재생성 전후 실측을 링크했다. A02 복귀·A05 카메라·머리 여유/구덩이/A06 순서로10~15분 재플레이 항목을 추가했다. 기존 V4와 Batch15 수락 대기 순서는 유지한다.

T2/T5는 REVIEW, 사용자 수락이나 Sprint Gate를 대신하지 않았다. 결정 대기0. V4 빌드·런처 보존, B13 삭제에 따른 TASKS 참조는 T5에서 현재 두 빌드로 함께 갱신했다. 설계 데이터 수정과 기존 Validation 덮어쓰기0. 기술 결과와 손맛 수락을 구분했다.

T7 종료 카드와 Backlog 결과는 끝날 때 같은 문서에 추가한다. 현재 링크 검사 결과와 Quiet는 실제 실행 후 기록한다.

실제 확인: TASKS/README/인계/현재 배치 요약 로컬 링크0불량, 결정 대기0. Quiet B17-T6 REGRESSION 13/13. T6 DONE.
