# B20 T3 — 점프 머리 여유 측정

상태 DONE(측정). 판정은 MEASURE만 한다. V5 Scene6개 실제 BoxCollider2D를 Editor에서 읽었으며 저장하지 않았다. Player 프리팹은 0.7×1.6. 높이1.6/1.3/1.1에 맞춰 폭도 균일 축소한 가정으로 수직 여유를 구했다. 이동·점프·중력 값 변경 없음.

표의 수는 샘플 수가 아니라 원본 면 수다. 각 solid/platform의 노출된 윗면을 한 면으로 세며 벽의 서 있을 수 있는 윗면도 포함한다. 내부에 덮인 위치·방 지붕 외부는 제외한다. 0.25u 격자와 양끝·중앙·가장자리 ±0.345u(몸 반폭0.35에서 양의 겹침0.005)를 검사한다. 한 면 안에서 최소 c를 사용하므로 면 전체가 좁다는 뜻이 아니다. c=999는 위쪽 막는 콜라이더가 없는 샘플이다.

실제 점프 발 상승: 짧음 1.00800u / 풀 2.52002u. 짧음은 이륙 관측 직후 키 해제(약0.0333초), 풀은 유지. 연속식 계산은 풀2.4u / 즉시 cut0.6u이며 분류에는 실측을 썼다. [T2](B20-trench.md).

a(c<2.2)는 기존 기준 표시로 별도 집계하며 b/c/d와 중복 가능하다. b는 c<h+짧음, c는 h+짧음≤c<h+풀, d는 c≥h+풀이다. 비교 오차0.003u. 샘플별 최소 c는 양의 가로 겹침0.003u 이상인 위쪽 콜라이더의 바닥면까지 잰다. 아래/옆 구조물은 수직 머리 여유와 구분한다.

Claude의 대략22면/짧음16면과 동일하다고 주장하지 않는다. 이번 집계는 벽 윗면·문 주변·가장자리 반폭 확장까지 모두 포함하고, 짧은 점프는 명시한 실제 키 해제 recipe를 사용했다. 후보는 최소 여유 기준이며 실제 체감 문제로 확정하지 않는다.
