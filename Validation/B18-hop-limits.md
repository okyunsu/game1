# B18 BL3 — 실제 입력 점프·포고 한계

측정만 수행. 실제 PlayerMotor/PlayerAttack과 프리팹 수치를 유지한 Development 전용 분리 arena(2000,1000)를 사용한다. 매 시험 시작 위치만 초기화하고, 이후 입력 점프·이동만 사용했다. 더블 점프·대시·벽 점프 없음. 가로0.25u 격자, 이륙은 왼쪽 끝 직전, 달리기/제자리 두 방식, 점프 키 유지. 상승량은 발 높이 기준, 가로 간격은 두 발판 끝 사이 거리.

|0.00|4.50|4.75|
|1.00|4.00|4.25|

|2.50|2.50|3.00|
