# B21 T7 — 36면 머리 여유 부족분

DONE(측정·계산). Claude 설계 변경 `7d40918`은 지름길 잠금/방향 계약뿐이다. Design·Scene 배치를 수정하지 않았다. 선행 T4 실측은 [가로 한계](B21-gaps.md)에 완료했다.

B20의 실제 Collider에서 추출한 h1.6 후보36면(실제 접촉33/36)을 같은 순서로 사용했다. 이 목록을 새 Unity 접촉36회로 오해하지 않는다. T2 재생성 전후 기하 동등 확인을 바탕으로 현재 승인 JSON의 면/구조물 y를 대조했다. 필요 여유는 지시된 `1.6+2.52+0.1=4.22u`, 부족분=max(0,4.22-현재 여유)다.

오름은 **이 행의 서 있는 면 윗면→위 구조물의 올린 뒤 윗면**으로 계산한다. 실제 경로의 다른 중간 발판을 통한 도달 가능성은 판정하지 않는다. 천장 충돌은 방 상단을 막는 기존 고체와 올린 구조물의 양의 영역 겹침, 외곽 초과는 방 높이 초과로 구분한다. 천장 자체인 행은 별도 표시한다. 설계 수정안·채택을 제시하지 않는다.
