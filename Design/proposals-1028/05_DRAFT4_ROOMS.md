# 05 — draft4 방 사양 (방 세션: Claude Code)

대상: `Design/v5/rooms_v5_A.json`, `world_v5_A.json`, `WORLD_V5.md`(13절 신설), `ascii_A.txt`.
**Unity 실행 금지.** 04 계약 값은 바꾸지 않는다. A01·A02·A06은 이번에 손대지 않는다(선택 항목 제외).

## 원칙

- 방마다 "여기서 무슨 일이 일어나나" 한 줄. 한 줄이 안 나오면 요소를 넣지 말고 보고한다.
- 흐름은 **소개 → 시험 → 조합**. 같은 요소를 반복 배치해서 길이만 늘리지 않는다.
- 새 부품을 만들지 않는다. 이미 있는 것만 쓴다: E1·E2·E3·E4, 무너지는 발판(CrumblePlatform), 증기(SteamVent), 승강기(LeverLift), 가시·hazard(DamageBlock), 등불 포고(PogoTarget). 신규는 hazard 복귀(12-1)와 보스1뿐.

## 고리 흐름(첫 플레이)

A01 → A02 → **A03 허브**(쉼, CP) → 동쪽 위 → **A04**(두 갈래 → 보스1) → 구멍 → **A05**(대시 획득 → 도랑을 대시로 건너 첫 사용) → A03 → **A03 서쪽 위 대시 연습** → 대시 문(B01 stub) 확인.
- 보스 전 A03 → A05 직행: 들어가면 도랑 서쪽(x0~6)에 서서 건너편 사당을 본다. 도랑에 닿으면 복귀. **보이지만 못 가는 곳.**

## A03 허브 — "쉬면서 세 갈래와 대시 문을 본다"

- 적 4 → **0** [추천·미확정 D-HUB-ENEMY. 사용자가 1을 고르면 동쪽 아래 E1 1마리만 남김]
- 체크포인트 **CP-A03** 추가: 거리(아래) 중앙, 구덩이와 겹치지 않는 평지.
- 문 `A05-A03`에서 `closed_until_wall_broken` 제거(일반 양방향 문).
- **대시 연습 구간(서쪽 위)**: 위 마을(y8.5 발판) → 대시 문 선반(y14.5) 사이를 대시가 있어야만 건너는 3단계로 바꾼다.
  1. 평지 간격 약 5.5u (일반 점프 최대 4.75u 초과, 달리기 점프+공중 대시로 통과)
  2. 약간 오르며 건너는 간격
  3. 아래가 hazard(복귀 지점 = 1단계 시작)인 간격
  - 대시 전에는 선반이 보이지만 못 가야 한다. 기존 등불 Lu2 경로가 대시 없이 선반에 닿게 하면 Lu2를 옮기거나 제거한다.
  - 정확한 간격 수치는 Batch22 도랑 측정값이 나오면 맞춘다. 지금은 후보로 적고 `WORLD_V5.md`에 "측정 후 확정" 표시.
- 위 마을 ↔ A02 중간 선반 고리(문 `A02-A03U`)는 능력 없이 그대로 유지.

## A04 폐수로 — "쉬운 길과 위험한 길 중 고르고, 끝에서 보스를 만난다"

- 오른쪽 절반 x24~49는 **04 계약 C-1 아레나**. 기존 위 통로 발판(x21~42, y6.4)·산성 도랑 x22~40·등불 L1~L4·섬 고체 x29.5~32.5는 아레나와 겹치므로 **왼쪽 x0~23 안으로 다시 배치**한다.
- 왼쪽 x0~23 구성(두 갈래 유지):
  - 위 길(쉬움): 블록·발판으로 올라 위에서 아레나로 내려가는 길
  - 아래 길(어려움): 짧은 산성 도랑 + 등불 포고 2~3 + 섬의 숨은 조각. 도랑에 `hazard_return`(도랑 입구) 지정
  - 두 길 모두 x24~27 바닥으로 내려와 아레나에 들어간다(C-2 안전 착지).
- 일반 적 3 → **1**(왼쪽 위 길의 E1). 아레나 안에는 일반 적 없음.
- 보스 데이터 `boss` 필드(C-6) 추가. 문 `A04-A05`는 유지, `floor_cover` 추가.
- 왼쪽이 좁아 두 갈래가 안 나오면 아래 길(도랑·조각)을 빼고 보고한다. 보스 아레나 폭이 우선.

## A05 대시 사당 — "대시를 얻고, 그 대시로 바로 도랑을 건넌다"

- `breakable`, `breakable_side` 제거. 마크 "부서지는 벽" 제거.
- 도랑 x6~12 유지, `hazard_return` 지정: 서쪽 접근은 x3(도랑 서쪽), 동쪽 접근은 x13.5. (방향별 복귀가 생성기에서 안 되면 하나의 복귀 지점 = 들어온 쪽 가까운 바닥으로 정의하고 보고)
- 도랑 폭은 **Batch22 측정 후 확정**. 합격 기준: 능력 없이 10회 통과 0, 대시 보유 10회 통과 10. 6u가 기준을 못 맞추면 측정이 제안하는 폭으로 바꾸되 방 크기 50은 유지.
- 서쪽 바닥 x0~6에서 사당(x37.5)이 화면에 보이는지 확인할 메모를 남긴다(카메라 폭 약 19.6u라 직접 보이지 않을 수 있음 → 사당 빛을 도랑 쪽으로 새게 하는 표식 등 그래픽 단계 후보로 기록).
- E1 1마리 유지. 첫 대시 사용은 도랑 하나로 충분하다(연습은 A03에서).
