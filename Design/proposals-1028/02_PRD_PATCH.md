적용 규칙: "수정 전" 문장이 저장소와 다르면 적용하지 말고 보고한다. 기준 `544ea5e`.

## 1. 27행 근처 — 핵심 흐름

수정 전
> 이동·점프·탐색 → 능력 게이트 관찰 → 능력 획득 → 짧은 재방문 → 게이트 통과 → 다음 능력 → 최종 보스(Slam 획득) → S01 단일 엔딩 → A01 재개 후 Slam 재방문.

수정 후
> 이동·점프·탐색 → 능력 게이트 관찰 → 보스 또는 능력 획득(보스1·3은 처치 후 능력, 보스2·4는 능력을 써서 처치) → 다음 방에서 능력 연습 → 게이트 통과 → 다음 능력 → 최종 보스(Slam 획득) → S01 단일 엔딩 → A01 재개 후 Slam 재방문.

## 4. 67행 진행

수정 전 첫 문장: `진행은 Dash(A05) → 벽 점프(B04) → Double Jump(C05) → 보스(C06 처치 시 Slam 획득) → ...`
수정 후: `진행은 보스1(A04) → Dash(A05) → 벽 점프 획득 후 보스2(B04) → 보스3(C05) 처치 → Double Jump → 최종 보스(C06, 처치 시 Slam 획득) → ...`
같은 문단의 `보스 처치 외 열쇠·수집품·퀘스트 조건은 없다.`는 유지.

## 5. 71행 전투

수정 전: `2페이즈 외 변신·소환전·미니보스를 추가하지 않는다.`
수정 후: `중간 보스 3종(1페이즈, 패턴 2~3개)은 기존 보스 코드와 기존 적 행동을 재사용한다. 변신·소환전은 추가하지 않는다.`
