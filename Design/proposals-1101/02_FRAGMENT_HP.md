# 02 — 조각 4개 = 최대 HP +1 (P3, 사용자 승인 필요)

**왜 승인이 필요한가:** PRD 71행 "일반 적은 … 드롭·경험치·성장은 없다", 111행 제외 목록과 부딪힌다. 수집 보상으로 성장(최대 HP)이 생기므로 범위 예외다.

**왜 추천하나:** 사용자 플레이 의견 "막힌 길·숨은 요소가 있어야 한다"를 살리려면 숨은 곳에 갈 이유가 있어야 한다. 지금 조각은 모아도 아무 일이 없다. Hollow Knight 가면 조각처럼 4개 = 최대 HP +1이면 층 A 첫 통과(3개) + 대시 재방문(1개)으로 첫 보상이 완성된다.

## 규칙(초안)
- 조각(DiscoveryReward)을 주우면 저장(조각 ID 단위). HUD에 `조각 n/4` 표시.
- 4개마다 최대 HP +1, 즉시 HP 전부 회복, 획득 안내 1.5초.
- 저장: 조각 ID 목록 + 최대 HP 보너스. 새 게임 초기화.
- 층 A 조각 6개(A01 2, A02 2, A04 1, A06 1) → 최대 +1(4개), 나머지 2개는 층 B 조각과 합쳐 다음 +1.

## PRD 패치(승인 시 Codex가 그대로 적용)
- 71행: `일반 적은 단순 행동과 재시도용 초기화만 제공하고 드롭·경험치·성장은 없다.` → `일반 적은 단순 행동과 재시도용 초기화만 제공하고 드롭·경험치는 없다. 성장은 숨은 조각 4개마다 최대 HP +1(D-FRAGMENT-HP)뿐이다.`
- 83행 저장 목록 `…보스별 처치(보스 ID 단위)·` 뒤에 `조각 ID·최대 HP 보너스·` 추가.
- 111행 승인 예외 괄호 끝 `위험 지형 복귀(D-A05-TRENCH)` 뒤에 `, 조각 최대 HP(D-FRAGMENT-HP)` 추가.
