# 03 — 보스2 "벽 감시자" 사양 (P4, 시험 아레나)

원칙(GAME_DESIGN 13절 D-BOSS4): 짝수 보스 = **얻고 싸운다**. 벽 점프를 얻은 직후, 나가려는 순간 갇히고, 벽 점프를 써야 이긴다. 실제 위치는 층 B(B04 예정) — 층 B 방 설계 전이므로 이번에는 `BossTest_B2` 시험 씬에서 완성하고, 방에는 나중에 붙인다(보스1과 같은 방식).

## 아레나 (BossTest_B2, 로컬 좌표)
| 항목 | 값 |
|---|---|
| 크기 | 안쪽 폭 22 × 높이 14 (x1~23, y1~15) |
| 양쪽 벽 | x0~1, x23~24 전체 높이 **ClimbableWall**(벽 미끄러짐·벽 점프) |
| 바닥 | y1 평지. 발판 없음 |
| 입구 | 왼쪽 아래 문(x0, y1~4). 처음엔 열림 |
| 벽 점프 획득대 | 바닥 중앙 x12, 받침 고체 x10.5~13.5 상면2 |
| 트리거 | 벽 점프 획득 후 **획득대에서 가로 3 이상 멀어지면**(나가려는 순간) 입구 잠금 → 등장 연출 1.8초(보스1과 같은 틀, 천장에서 낙하) → 전투 |
| 처치 후 | 입구 열림, 처치 저장(보스 ID `B2-B04`) |
| 사망 | 벽 점프는 유지(획득 즉시 저장), 체크포인트 복귀, 재진입 시 획득대 비어 있고 같은 조건(획득대에서 3 멀어짐 대신 아레나 중앙 통과)으로 재시작 |

## 보스2 (1페이즈, HP 26, 피해 1)
| 순서 | 패턴 | 예고 | 의도한 회피 | 바탕 |
|---|---|---|---|---|
| 1 | **높은 충격파**(양방향) | 0.7s 바닥 | 높이 2.8 → 일반 점프(최대 2.52)로 못 넘음. **벽에 붙어 미끄러지거나 벽 점프로 위로** | 기존 충격파(waveHeight 1 → 2.8, 양방향) |
| 2 | **벽까지 돌진** | 0.5s | 벽에 붙어 있으면 맞음 → 벽 점프로 반대편 위로 넘기 | 기존 돌진(벽 앞 정지) |
| 3 | **천장 낙하물** 3지점 | 0.8s | 안전 지대에 서 있기(벽에 붙어 있으면 위험) | 기존 낙하물 |

- 1→2→3 반복, 회복 1.0s. 첫 사이클의 1번은 예고를 1.0s로 길게(학습).
- 약점: 보스 위 포고 가능, 좌우·위 공격.
- 합격 기준(자동): ① 벽 점프 **끈** 상태 자동 입력 10회 모두 1번 패턴에 피격(벽 점프 없이는 못 피함) ② 벽 점프 켠 상태 고정 입력으로 처치 ③ 트리거·잠금·연출·저장·재진입 ④ B1·B3 회귀 무변화.
- 목표(사람): 첫 승리 3~6분, 숙련 1~2분. 수치는 BossCandidates/B2 Asset.
