# 02 — 그래픽 1차: 직접 제작 아트 v1 (트랙 C)

결정(사용자 2026-11-02): 외부 에셋을 받지 않고 **직접 디자인**. 원본: `Design/art_v1/`.
- `make_art.py` — 모든 타일·배경을 코드로 그린다(외부 이미지 0). `palette.json`의 색을 바꾸고 다시 실행하면 전체가 바뀐다.
- `mock.py` — 실제 방 데이터(`rooms_v5_AB.json`)에 타일을 입혀 목업 PNG를 만든다(`mockups/`). Unity 없이 미리 보기.
- 규격: 16px = 1u(Unity 16 PPU), 발판·산성·가시는 8px 높이 띠.

## 아트 방향 (스토리: 모두가 정상을 향해 오르는 수직 메트로폴리스)
| 층 | 분위기 | 벽 | 발판 | 배경 |
|---|---|---|---|---|
| A 아래 거리 | 밤, 젖은 벽돌, 나트륨 가로등 주황 | 보라빛 회색 벽돌, 윗면 주황 불빛 테두리 | 나무·쇠 발코니 | 창문 켜진 주거 빌딩 실루엣(어둡게) |
| B 공장 | 녹, 청록 강철, 증기 | 리벳 강판 + 녹 얼룩, 윗면 노란 경고 점선 | 철망 캣워크 | 굴뚝·배관 실루엣, 연기 |

## 읽힘 규칙 (게임플레이 우선)
1. **서 있을 수 있는 윗면은 가장 밝은 선**(A 주황, B 밝은 회청).
2. **벽 점프 벽 = 노랑/검정 경고 줄무늬**(층 공통). 다른 곳에 이 줄무늬를 쓰지 않는다.
3. **위험(산성)은 가장 채도 높은 초록**, 가시는 밝은 은색.
4. 무너지는 발판은 같은 발판에 검은 균열.
5. 문은 주황 틀, 능력 문은 능력 색(대시 청록 `#40e0d0`, 벽 점프 노랑 `#e3b23c`), 닫힌 stub은 붉은 틀.
6. 조각은 연두 빛 결정 + 은은한 빛무리(숨은 곳에서도 살짝 보이게).
7. 배경은 전경보다 밝기 55%·채도 60%로 눌러서 전경과 겹쳐 보이지 않게.
8. 플레이어: 노란 머리·청색 망토·노란 목도리(어떤 배경에서도 가장 따뜻한 색). 적: 보라.

## 매핑표 (생성기용)
| 데이터 | 스프라이트 |
|---|---|
| solid | `{층}_wall` 반복, 맨 위 줄은 `{층}_top` |
| platform | `{층}_plat` (crumble 인덱스는 `{층}_crumble`) |
| climb | `climb` |
| hazard | `acid` (가시 구덩이 표시가 필요한 곳은 `spike`) |
| doors(세로) | `door` (능력·stub은 틴트) |
| pogo lantern / spike | `lantern` / `spike` |
| marks '조각' | `fragment` (+DiscoveryReward 위치) |
| lifts / steam | 기존 장치 표시 유지(승강기는 `B_plat` 위판, 증기는 반투명 기둥) |
| 배경 | `bg_A` / `bg_B`, 카메라 0.3배 패럴랙스 |
| 플레이어 / 적 | `player`(12×26) / `enemy`(16×16), 보스는 기존 도형 + 보라 틴트 |
